# 🧱 Section 5: Building a Robust BI Dashboard

Everything together on **UK bank customers**: 4,014 customers with gender, age, region, job classification, join date and balance.

The dashboard has a map of regions, a customer count card, gender pie, age and balance histograms and a tree map of job classification.
